# 자전거 대여량 예측

작성: 데이터 탐정단

## 1. 탐구 질문
시간과 날씨가 주어지면 대여량을 얼마나 잘 추정할 수 있을까?

## 2. 데이터 출처와 범위
- 출처: 수업용으로 생성한 공공자전거 가상 자료
- 주소: 외부 출처 없음
- 이용 조건: 수업에서 활용·수정 가능. 실제 도시의 관측 통계로 인용하지 않기.
- 범위: 가상 도시, 2024-04-01~2024-04-30, 720시간. 오류와 중복을 넣은 정제 연습용 723행.
- 읽은 행 723 → 정제 후 720

## 3. 정제 이유
이상치와 결측치를 제거하여 데이터의 품질을 높이고 분석 결과의 왜곡을 방지했습니다.

## 4. 그래프와 해석

### 요일구분별 기온 합계 비교
요일구분별 전체 대여량 합계를 비교해보면 평일 대여량이 주말에 비해 압도적으로 높게 나타납니다. 하지만 이는 평일(약 22일)과 주말(8일)의 총 일수 차이에서 오는 단순 누적 효과일 수 있으므로, 요일별 일평균 대여량이나 시간당 평균 대여량을 함께 비교하는 것이 더 정확합니다.

사용 718행 / 빈값 제외 2행. 범주별 기록 수를 함께 확인하세요. 합계와 평균은 다른 질문입니다.

### 기온 × 대여량: 함께 변할까?
기온과 대여량의 산점도를 보면 기온이 약 10도에서 20도 사이로 따뜻해질수록 대여량이 눈에 띄게 증가하는 양의 상관성을 보입니다. 그러나 특정 고온 구간에서 대여량이 다시 감소하거나, 비가 오는 날씨 등 기온 외의 날씨 요인에 의해 기온이 적당함에도 대여량이 0에 가까운 특이치가 존재합니다.

유효 718행 중 718개 점 표시(1,500개 초과 시 고정 무작위 표본). 관계는 원인의 증거가 아닙니다.

### 일별 기온 평균의 변화
4월 한 달간 일별 대여량 평균의 변화를 살펴보면 주기적으로 대여량이 상승했다가 하강하는 흐름이 관측됩니다. 이는 주중과 주말의 이용 패턴 주기와 밀접해 보이지만, 기온이 급격히 떨어지거나 강수량이 많았던 특정 일자의 기후 변화 역시 대여량 급감에 큰 영향을 주었을 것입니다.

사용 717행 / 날짜·값 누락 제외 3행. 관측값 없는 기간은 선으로 이어 붙이지 않습니다.

### 요일구분별 기온의 퍼짐 비교
요일구분별 대여량의 분포(상자그림)를 보면 평일과 주말의 중앙값과 데이터 퍼짐 정도(IQR)가 서로 유사한 흐름을 보입니다. 평일의 대여량 상한선이 조금 더 높게 형성되어 있으나, 이는 단순히 출퇴근 시간대의 집중 이용으로 인한 영향일 수 있으므로 시간대별 세부 분석이 추가로 필요합니다.

사용 718행. 상자는 가운데 50%의 범위입니다. 수염 밖 값은 확인 후보이지 자동 삭제 대상이 아닙니다.
